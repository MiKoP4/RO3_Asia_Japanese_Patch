RO3 Asia 日本語化パッチ
======================

表示翻訳の補完（DLL 2.7.4）
--------------------------
敵名・スキル名のMeshUIと通常UIの表示直前に、既存辞書の訳文を適用します。
Goblin Archer、Magnus Exorcismus!!、イベント参加のクエスト説明、数値入りサーバーレベル案内を対象に回帰テストを追加しました。
ゲーム起動時にUnityコンポーネントが破棄されても、描画翻訳フックを保持します。
クエスト欄の複合文言・一部翻訳済みのサーバー案内にも対応しています。
実機を再起動して敵名・スキル名・クエスト説明・サーバーレベル上限の日本語表示を確認しました。
Recoveryファイルへの書き込みは再開していません。

起動不能からの復旧（2026-09-23対応）
----------------------------------
RO3とRO3AsiaLauncherを終了し Recover-Japanese.bat にClientフォルダを指定します。
旧日本語化DLLを無効化し、manifestと英語・簡体字・繁体字の4ファイルを元バックアップから復元します。
導入記録がなくても利用できます。バックアップは削除しません。
不足・不一致で停止した場合は旧DLLが無効になった状態で公式ランチャーの修復を使用してください。
修復後もバックアップ不足で停止する場合は、次の手順で古い記録を退避できます。
1. RO3AsiaLauncherのRepairを完了し、ランチャー経由でゲームが起動することを確認します。
2. ゲームとランチャーを終了します。
3. Recover-After-Official-Repair.batに同じClientを指定し、REPAIREDと入力します。
   現在のmanifestに記載された英語・簡体字・繁体字ファイルのSHA-256とサイズを照合します。
   既知の日本語化済みmanifestや不整合が残っている場合は停止します。
   この照合だけでは公式ファイルであることは証明できないため、必ず先に公式Repairを完了してください。
   古いバックアップと状態記録はClientの隣のRO3-Recovery-Backup-から始まるフォルダへ保管します。
   現在のゲーム本体は書き換えません。退避した古い記録はClientへ戻さないでください。
4. Install-Japanese.batで日本語化を再導入します。Updateは最新版判定で省略される場合があります。
Repairが失敗した場合やゲームが起動しない場合は、修復後専用BATを実行しないでください。
改善版 Install-Japanese.bat もコピー前に同じ復旧処理を実行します。
新版は署名対象のRecoveryを書き換えず、メモリ上の翻訳を使います。
早期読み込み時に確定するスキル条件など、一部の翻訳が従来版より減る可能性があります。
必ずRO3AsiaLauncherから起動してください。ro3.exe直接起動は起動証明不足で終了します。
実機のログイン・全翻訳表示の確認は別途必要です。

インストール
------------
1. RO3を終了します。
2. このZIPを任意のフォルダへ展開します。
3. Install-Japanese.bat を実行します。
4. ro3.exe があるRO3の Client フォルダを指定します。
   ro3.exe または Client フォルダをBATファイルへドラッグ＆ドロップして指定することもできます。
5. [OK] と表示されたら、RO3を起動します。

初回導入時に1回のBAT実行だけでは翻訳が反映されない場合があります。
その場合は、RO3を終了した状態で Install-Japanese.bat をもう一度実行し、RO3を再起動してください。

以前のバージョンが導入済みの場合も、そのまま上書きインストールできます。

自動更新
--------
1. RO3を終了します。
2. 展開済みのReleaseフォルダにある Update-Japanese.bat を実行します。
3. ro3.exe があるRO3の Client フォルダを指定します。

アップデーターはGitHub Releasesから最新版を確認し、必要な場合だけダウンロードして更新します。
GitHub側でSHA-256が提供されている場合は、整合性を確認してから展開します。
GitHubへ接続せず、展開済みのReleaseに含まれるファイルで更新する場合は、Update-Japanese.bat に --local を指定します。
例: Update-Japanese.bat --local "C:\Games\RO3\Client"（Clientフォルダを省略すると、後から入力できます）

アンインストール
----------------
RO3を終了し、Uninstall-Japanese.bat を実行してゲームの Client フォルダを指定してください。
パッチ導入前から存在した共有BepInEx環境は自動削除しません。
